# 🌻 Flores Amarillas

Página web romántica interactiva hecha con HTML, CSS y JavaScript puro.

## ¿Qué tiene?

- 🌸 Jardín 3D animado con flores que florecen al cargar la página
- 🐱 Gatitos grises atigrados animados a los lados
- ✨ Efecto de partículas brillantes de fondo
- 🖱️ Movimiento de cámara con el mouse (parallax)
- 💌 Botón de "Mira mi carta" que abre una cartita editable

## Cómo verlo

Abre el archivo `Flores.html` directo en tu navegador, o si activas **GitHub Pages** en este repositorio (Settings > Pages), puedes verlo en vivo desde un link.

## Tecnologías

- HTML5 / CSS3 (animaciones y variables CSS)
- JavaScript vanilla (canvas para partículas)
- Tailwind CSS (vía CDN)
- Google Fonts
